# ADR 使用规范

ADR（Architecture Decision Record）记录重要架构决策的背景、选项、取舍和后果。

## 文件命名

```text
NNNN-short-decision-title.md
```

编号只递增，不复用。ADR 一旦被接受，不通过重写历史来改变结论；新的决策使用新编号，并把旧 ADR 标记为“已废弃”。

## 状态

- 提议中：正在讨论，尚未进入实现。
- 已接受，待实现：决策确定，但代码尚未完成。
- 已实现：决策已被代码和实验验证。
- 已废弃：被新的 ADR 替代。
- 已拒绝：讨论后决定不采用。

## 模板

```markdown
# ADR-NNNN：决策标题

- 状态：提议中
- 日期：YYYY-MM-DD

## 背景
当前出现了什么问题？如何复现？

## 决策
我们决定做什么？明确边界是什么？

## 备选方案
还考虑过哪些方案？为什么暂不选择？

## 代价与风险
这个决定增加了什么复杂度？不能保证什么？

## 验证标准
用哪些测试、指标或故障实验证明决策成立？

## 重新评估条件
出现什么证据时需要重新决策？
```
